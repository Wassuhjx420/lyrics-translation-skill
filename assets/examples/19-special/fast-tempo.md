# 快歌处理示例

## 翻译要点
快速歌曲（BPM 140+）中，歌词密集，翻译需大幅精简。

## 策略一：精简表达

```
原文(8个单词): "I never thought that I would feel this way"
直译(10字): "我从未想过我会有这样的感觉" ❌ 太长
精简(7字): "从没想过会有这感觉" ✅
更精简(5字): "未曾想过会这样" ✅（嘻哈/快歌推荐）
```

## 策略二：使用单音节词

```
原文: "Everything is going to be alright"
翻译: "一切都会好的"（含"的"4字）
精简: "一切都会好"（3字，省略"的"）

原文: "I will always love you"
翻译: "我会永远爱你"（6字）
精简: "永远爱你"（4字，省略主语）
更精简: "永爱你"（3字，文言化）
```

## 策略三：删除衬词

```
原文: "And it feels like we're flying so high tonight"
含衬词: "然后感觉就像我们今夜飞得如此之高" ❌

精简版1: "感觉今夜我们高飞" ✅（删"然后""就像""如此之"）
精简版2: "今夜我们飞向高空" ✅（调整表达）
```

## 策略四：合并短句

```
原文: "I came, I saw, I conquered"
逐译: "我来了，我看到了，我征服了"
合并: "我来我见我征服"（更简洁有力，适合快歌）
```

## 示例对比

### EDM快歌
```
原文:
We're gonna party all night long
Everybody sing our song
Ain't nobody bringing us down
We're the kings of this town

译文(精简):
整夜狂欢不停歇
大家一起唱这歌
没人能把我们拉下
我们是这城的主宰

译文(更精简):
整夜狂欢
大家唱
没人拉
咱称王
```

## 通用原则
- **优先保留含义**：核心信息 > 修饰语
- **删减"的、了、着、过"等助词**：不影响含义
- **省略代词**：中文上下文清楚的代词可省略
- **用字代替词**：单字词替代双字词
