# 极简风格处理示例

## 翻译要点
极简风格歌词（如Bon Iver、Sigur Rós等）通常字数极少，意义开放。

## 原则一：保持简洁

```
原文: "Skin, love, light"
直译: "皮肤，爱情，光芒" ❌ 过于具体
更好: "肤，爱，光" ✅ 保持极简和开放性
```

## 原则二：注重留白

```
原文: "still" (一个词作为一句)

可选译文: "依然" / "静止" / "安" / "仍"
*每个选项开启不同的解读方向
*推荐根据上下文选择，保留模糊性
```

## 原则三：强化意境

```
原文:
river
flow
home

译文:
河
流
家

保留三联词的意象张力和开放性
```

## 完整示例

### 极简风格
```
原文:
You
Me
Sea
Free

译文:
你
我
海
自在
```
（注释："Free"译为"自在"而非"自由"，更简洁且有意境）

### 梦幻极简
```
原文:
Weightless
Breathless
Endless

译文:
失重
屏息
无尽
```
（三词押韵：重/息/尽使用不同辙口，以意境为主）

## 一般建议
1. 极简歌词不要扩充，保持单字/双字
2. 一个词可以有多个中文选项，选最具诗意感的
3. 句式结构不对称也没关系——简洁本身就是美
4. 不必强行押韵，意境优于韵律
