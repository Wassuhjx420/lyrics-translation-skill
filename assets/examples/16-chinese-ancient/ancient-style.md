# 古风歌曲 - 中国风翻译示例

## 歌曲信息
- **原唱**：虚构示例
- **流派**：中国古风
- **特点**：从现代中文到更古典的中文表达，展示古风翻译精髓

## 翻译示例

### 现代版歌词（原文风格）
```
桃花落在我的肩头
春风吹过古城楼

我想起了你的笑容
像那明月照江流

### 古风版译文
```
桃花零落肩上尘
春风又度旧城门

思君不见君之颜
明月皎皎照江深

### [Verse 2 - 现代版]
```
时光匆匆不停留
我在城头等好久

你说过要一起走
如今只剩我独守

### [Verse 2 - 古风版]
```
流光易逝去难收
独倚城楼望穿秋

曾许诺言共白头
如今只剩月如钩

### [Chorus - 现代版]
```
桃花依旧笑春风
人面不知何处去

年年岁岁花相似
岁岁年年人不同

### [Chorus - 古风版]
```
桃花灼灼笑东风
人面不知何处踪

年年花似去年好
岁岁人非旧时容

## 翻译要点
- **词汇转换**：现代→古风
  - "落在"→"零落"
  - "春风吹过"→"东风又度"
  - "我想起"→"思君"
  - "时光匆匆"→"流光易逝"
  - "好久"→"望穿秋"

- **对仗**："年年花似去年好 / 岁岁人非旧时容"——化用刘希夷名句

- **押韵**：使用人辰辙(en)和人辰/言前混押：
  - 肩/门/颜/深（言前/人辰通押）
  - 收/秋/头/钩（由求辙）
  - 风/踪/好/容（中东/言前混押）

- **典化用**：
  - "人面不知何处去"化用崔护《题都城南庄》
  - "桃花依旧笑春风"化用同诗
  - "月如钩"化用李煜《相见欢》
