# 双语歌词对照模板

## 使用说明
本模板用于输出最终的翻译结果。严格按照以下格式，仅输出原歌词和译文，不添加额外注释。

## 输出格式

```
[段落名称，如 Verse 1、Chorus、Bridge 等，可选]

[原歌词第1行]
[译文第1行]

[原歌词第2行]
[译文第2行]

[原歌词第3行]
[译文第3行]

...

[下一个段落]

[原歌词]
[译文]
...
```

## 完整示例

```
[Verse 1]
Imagine there's no heaven
想象这世界没有天堂

It's easy if you try
只要你用心，这并不难

No hell below us
脚下没有地狱

Above us only sky
头顶只有天空

[Chorus]
Imagine all the people
想象所有的人们

Living for today
只为今天而活

[Verse 2]
Imagine there's no countries
想象这世界没有国界

It isn't hard to do
这并不难做到

Nothing to kill or die for
没有杀戮，没有牺牲

No religion too
也没有宗教之分

[Chorus]
Imagine all the people
想象所有的人们

Living life in peace
和平地生活
```

## 注意事项
1. 原文在上，译文在下
2. 每组之间用空行分隔
3. 保持原歌词的段落结构
4. 不添加翻译说明或注释
5. 如需要，可标注段落名称
