# 中国古风 歌词翻译指南

## 流派概述
古风音乐是中文原创音乐的重要流派，融合中国传统文化元素与现代音乐创作。歌词大量使用文言词汇、古诗词句式和传统意象，追求古典意境和典雅美感。

## 翻译核心原则
- **文言典雅**：使用古诗词用语，保持古典美感
- **意境优先**：古风歌曲重在意境营造
- **严格押韵**：遵循古诗词的押韵传统

## 翻译技巧详解

### 文言词汇表
| 现代词汇 | 古风替代 | 说明 |
|---------|---------|------|
| 你 | 君/卿/汝/尔 | 根据关系亲疏选择 |
| 我 | 吾/余/予 | 第一人称 |
| 这/那 | 此/彼/斯 | 指示代词 |
| 在 | 于/乎 | 表处所 |
| 的 | 之 | 所有格 |
| 是 | 乃/为/即 | 判断句式 |
| 来 | 至/临 | 趋向动词 |
| 看 | 观/望/览/眺 | 视觉动作 |
| 想 | 思/念/忆 | 心理活动 |
| 说 | 曰/云/道/言 | 言语动词 |

### 句式处理
- **五言/七言句式**：参考古诗词的句式结构
- **对仗工整**：上下句对仗是古风的重要特征
- **典故化用**：可引用或化用古诗词名句
- **省略连接词**：文言文中连词使用较少

### 韵律处理
- **严格按照古诗词押韵传统**
- **近体诗押韵规则**：偶数句押韵，一韵到底
- **词牌格律**：若有明确词牌需遵守
- **推荐辙口**：言前(an)、人辰(en)、江阳(ang)

## 常见问题与解决方案
- **问题**：现代词汇破坏古典美感
  - **方案**：寻找文言替代，如"手机"→"传讯玉"（创意转化）
  - **底线**：实在无法转化的现代概念，直接使用

- **问题**：古今词义差异
  - **方案**：确认文言词汇的正确含义，不误用

## 特殊要求
- **历史准确性**：涉及特定朝代的歌词，用词需符合时代
- **典故出处查证**：确保典故使用准确
- **诗词流派一致**：婉约/豪放/山水等风格的统一
