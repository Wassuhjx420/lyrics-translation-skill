# 朋克 歌词翻译指南

## 流派概述
朋克摇滚（Punk）是摇滚乐的子流派，以快速、短促、激烈的演奏为特征。歌词直接粗暴，充满对社会体制的批判和反叛精神，拒绝精致和商业化。

## 翻译核心原则
- **粗暴直接**：不需要修饰，越直接越好
- **短促有力**：每句话都要像一记重拳
- **保留愤怒**：朋克的愤怒是其核心，不能弱化

## 翻译技巧详解

### 词汇选择
- **激烈词汇**：滚、废、烂、死、砸、烧、干
- **俚语脏话**：去他妈的、狗屁、扯淡（根据发行审查调整）
- **拒绝文雅**：避免"优雅""精致""美丽"类词汇

### 句式处理
- **极短句**：2-5字为佳
- **祈使句**：No future! → 没未来！/ Fuck you! → 去你的！
- **断裂的语法**：不需要完整的句子结构

### 韵律处理
- **韵律自由**：朋克的韵律很灵活
- **节奏比押韵重要**
- **AAA等简单模式**

## 常见问题与解决方案
- **问题**：朋克歌词过于简单，翻译后更显单薄
  - **方案**：保持简单，不要为了"丰富"而扩充

- **问题**：政治性内容的敏感度
  - **方案**：忠实翻译但标明语境
