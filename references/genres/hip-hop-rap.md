# 嘻哈/说唱 歌词翻译指南

## 流派概述
嘻哈（Hip-Hop/Rap）是一种以说唱为核心的音乐形式，起源于1970年代的美国街头文化。歌词节奏感极强，注重韵脚密度和flow（说唱节奏流），语言风格高度口语化，常使用俚语、双关语和街头用语。

## 翻译核心原则
- **韵脚密度优先**：说唱的韵脚是灵魂，需最大化保留
- **保留街头感**：不要将俚语"雅化"
- **flow适配**：译文需匹配原曲的节奏和断句

## 翻译技巧详解

### 词汇选择
- **俚语词典**：
  - "Homie" → 哥们/兄弟/自家兄弟
  - "Dope/Fire" → 牛逼/炸了/绝了
  - "Money/Paper" → 钱/票子/钞票
  - "Hustle" → 拼/干/闯
  - "Real talk" → 说实话/讲真
- **脏话处理**：
  - 强烈语境：保留（妈的/操/他妈的）
  - 轻度语境：弱化（该死的/滚蛋）
  - 出歌需要审查：替换（TMD → 太猛的/太妙的）

### 句式处理
- **方言运用**：可适度使用中文方言词汇增强街头感（东北话、川渝方言等）
- **短句密集**：每句4-8字为宜
- **流水句**：说唱常有长串密集歌词，可使用逗号连接

### 韵律处理
- **高密度韵脚**：争取每2-4个字设置韵脚
- **句中韵**：不仅句末押韵，句中也可设置韵脚
- **多重韵**：多音节押韵（"方向"+"想象"、"力量"+"明亮"）
- **推荐辙口**：江阳(ang)、言前(an)、中东(eng)等洪亮辙口

## 常见问题与解决方案
- **问题**：英文双关语在中文中无法直译
  - **方案**：在中文中创造新的双关或使用谐音梗
  
- **问题**：英文原词的音节节奏与中文差距大
  - **方案**：使用衬词（嗯、啊、哟）填充节奏空缺

## 特殊要求
- **diss曲**：保留攻击性，火药味不能少
- **叙事说唱**：保证叙事的连贯性和清晰度
- **意识流说唱**：不必强行逻辑化，保留跳跃感
